### 5.1 타겟 변환

| KPI | 변환 | 역변환 |
|-----|------|--------|
| 예금총잔액 | `log1p(x)` | `expm1(x)` |
| 대출총잔액 | `log1p(x)` | `expm1(x)` |
| 순유입 | `sign(x) * log1p(abs(x))` | `sign(x) * expm1(abs(x))` |
| 카드총사용 | `log1p(x)` | `expm1(x)` |
